# Evolue - NFS — releases

Downloads públicos do **Evolue - NFS** (emissor de NFS-e de Fortaleza), um produto AnDevSistemas.

Baixe sempre a versão mais recente em:
https://github.com/andevsistemas/evolue-nfs-releases/releases/latest

Cada release traz o `EvolueNFS.exe` e sua assinatura `EvolueNFS.exe.sig` (Ed25519), conferida pelo próprio programa antes de instalar qualquer atualização.
